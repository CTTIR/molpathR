# molpathR: Molecular Pathology Data Platform for Clinical NGS Integration

A unified platform for ingesting, linking, querying, and visualizing
molecular pathology data from heterogeneous sources including NGS files
(FASTQ, BAM, VCF), XML variant interpretation reports, structured
pathology PDF reports, pathology and clinical information systems, and
survival outcome data. Provides a searchable in-memory database and an
interactive Shiny application for clinical exploration and cohort
analysis.
